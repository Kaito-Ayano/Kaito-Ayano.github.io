# 任务：银行流水 × 账面 逐笔勾稽与差异台账工具（recon）

## 背景与目标
我在准备财务岗位求职，需要一个小而完整的演示工具：把「银行对账单」与「银行存款日记账（账面）」逐笔勾稽，输出差异台账和银行余额调节表——这是会计「银行倒盘」工作的核心。数据在 `data/` 下，为合成的 2026 年 10 月样例（虚构公司「星桥贸易有限公司」，非任何真实企业数据），共两份 CSV，字段自解释。

## 工作方式（重要）
1. 先**复述你对需求的理解**，列出你的匹配规则方案（含歧义处理，如 1:1 约束、容差、优先级），**等我确认方案后再开始写代码**；
2. 分步实现，每步跑通再继续；
3. 全部完成后运行工具，给出结果摘要，说明每类差异的判定逻辑；我会人工抽查核对你的输出。

## 功能需求
工具 `recon.py`（Python，可用 pandas）：
1. 读入 `data/bank_statement.csv`（银行对账单）与 `data/ledger_entries.csv`（账面日记账）；
2. 逐笔 **1:1** 匹配（一条银行记录只能消耗一条账面记录，反之亦然）：
   - a. 参考号一致 → 直接配对（若参考号在任一侧出现多次，需报告并人工处理）；
   - b. 参考号无法配对的，按「金额 + 对方户名 + 日期（±3 天容差）」尝试唯一匹配；
3. 输出到 `output/`（CSV 文件 + 控制台摘要）：
   - `matched.csv`：已勾稽明细（标注匹配方式：参考号 / 模糊）；
   - `amount_mismatch.csv`：金额不符（参考号对上但金额不同，含差额列）；
   - `bank_only.csv` / `ledger_only.csv`：单边记录；
   - `date_shift.csv`：疑似日期错位（金额 + 户名 + 参考号一致但日期不同，含天数差）；
   - `duplicate_ledger.csv`：疑似账面重复（同参考号且同金额同日出现多笔）；
4. `reconciliation.csv` 银行余额调节表：截止日 2026-10-31，期初余额 1,280,000.00；从银行对账单期末余额调节到企业账面期末余额（或反向），逐项列示调节项目及金额，**合计必须与差异台账互相印证（对得上）**；
5. 所有差异台账增加一列「人工复核」（默认留空），人工填写后另存为 `*_reviewed.csv`，不覆盖原始输出。

## 约束
- 只用 Python + pandas，不联网、不新增依赖；
- 金额保留 2 位小数，日期格式 YYYY-MM-DD；
- 关键判断写注释，保证可解释、可复现。

## 验收清单（我会逐条检查）
- [ ] 四类差异台账齐全，且同一笔差异不在多张台账重复计数；
- [ ] 匹配严格 1:1，无重复消费；
- [ ] 调节表平衡，每一项调节都能对应到差异台账中的具体记录；
- [ ] 我人工抽查 3 笔差异，回原始 CSV 核对一致。
