银行流水 × 账面 逐笔勾稽工具（recon）

银行对账单 vs 银行存款日记账 · 差异台账与银行余额调节表 · 结果报告

项目说明

数据为全合成样例（虚构公司「星桥贸易有限公司」，2026 年 10 月），不含任何真实企业或个人数据，可用固定随机种子复现。 银行对账单与账面日记账各 57 笔。工具以 Python + pandas 无关的标准库实现，在「参考号配对 → 模糊匹配 → 单边归集」的 流程下完成严格 1:1 勾稽（每条记录至多被消费一次），并输出四类差异台账与银行余额调节表。

一、结果摘要

51成功勾稽（模糊匹配 0）
2金额不符
2日期错位
1疑似重复记账
2银行单边（企业未记）
1账面单边（未达账）

行级守恒核验：银行 57 行 ⟶ 勾稽 51 + 金额不符 2 + 日期错位 2 + 银行单边 2 = 57； 账面 57 行 ⟶ 勾稽 51 + 金额不符 2 + 日期错位 2 + 账面重复 1 + 账面单边 1 = 57。每行恰好被消费一次，无重复计数。

匹配规则

Pass 1（参考号）：参考号一致直接配对；参考号对上但金额不同 → 金额不符（含差额）； 金额相同但日期不同 → 日期错位（含天数差）；参考号在任一侧出现多次 → 报告并标记疑似重复。
Pass 2（模糊）：参考号无法配对的，按「金额 + 对方户名 + 收付方向 + 日期 ±3 天」就近唯一匹配。
余项：未被消费的记录归入单边——银行单边（企业未记）与账面单边（未达账）。

四、输出与复现

工具输出至 output/：matched.csv、amount_mismatch.csv、date_shift.csv、 duplicate_ledger.csv、bank_only.csv、ledger_only.csv 与 reconciliation.csv。 所有差异台账均含空的「人工复核」列，人工填写后另存为 *_reviewed.csv，不覆盖原始输出。

复现命令：python recon.py　　依赖：仅 Python 标准库（无第三方依赖、不联网）。
