# recon-tool · 银行流水 × 账面逐笔勾稽演示项目

为快手「财务会计师」岗位准备的「AI 应用经验」协作素材：在 Qwen Code 中与 AI 协作完成一个
**银行对账单 vs 银行存款日记账** 的逐笔勾稽工具（含差异台账与银行余额调节表）。

- 数据：**全部合成**（虚构公司「星桥贸易有限公司」，2026 年 10 月样例），无任何真实企业或个人信息。
- 目的：留下一段能清晰呈现「定义问题 → 方案确认 → 实现 → 人工复核」思路链的 AI 协作会话。

## 目录结构

```
recon-tool/
├─ data/bank_statement.csv   银行对账单（57 笔，含余额列）
├─ data/ledger_entries.csv   账面日记账（57 笔）
├─ docs/任务书.md            粘贴给 Qwen Code 的任务描述
└─ build_data.py             数据生成脚本（可重跑，seed 固定）
```

## 地面真值（埋入的差异，供人工复核 AI 输出用）

| 类型 | 参考号 | 说明 |
|---|---|---|
| 金额不符 | REF-20261003-007 | 银行 45,000.00 / 账面 45,600.00（账面多记 600.00） |
| 金额不符 | REF-20261015-032 | 银行 8,925.50 / 账面 8,955.50（账面多记 30.00） |
| 仅银行 | REF-20261008-012 | 账户管理费 120.00，账面漏记 |
| 仅银行 | REF-20261019-041 | 存款利息 86.40，账面漏记 |
| 仅账面 | REF-20261022-048 | 支票采购 15,000.00，10 月未兑付（未达账） |
| 日期错位 | REF-20261028-055 | 银行 10-27 / 账面 10-30（差 3 天） |
| 日期错位 | REF-20261009-015 | 银行 10-12 / 账面 10-09（差 3 天） |
| 账面重复 | REF-20261011-020 | 5,800.00 在账面记了两次（JZ-10xx 两张凭证） |

**期末差额（银行 − 账面）应 = 20,196.40**，按（银行 − 账面）口径构成：
未达账 +15,000 + 账面重复 +5,800 + 金额不符净额 −570（账面多记收入 600 → −600；账面多记支出 30 → +30）
+ 银行单边净额 −33.60（银行多记支出 120 → −120；银行多记收入 86.40 → +86.40）。
即 15,000 + 5,800 − 570 − 33.60 = 20,196.40。
调节表若不能逐项对上这些数，说明工具逻辑有问题——这就是「人工复核兜底」的验收点。
