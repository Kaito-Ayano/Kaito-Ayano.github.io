5. Инструмент построчной сверки «банк × учёт» (recon)

Личная работа · синтетические данные (вымышленная компания «Xingqiao Trading», октябрь 2026)

Сверка «банк × учёт» · отчёт о результатах (четыре реестра расхождений + акт сверки)
Строгое сопоставление 1:1: по номеру → по сумме + контрагенту + направлению + дате (±3 дня) → односторонние записи; четыре реестра расхождений (сумма, дата, дубли, односторонние) и сбалансированный акт сверки, каждый со столбцом ручной проверки.
Исходный код инструмента · recon.py
Только стандартная библиотека Python, без сторонних зависимостей и сети; воспроизводимо на данных с фиксированным зерном; правила с комментариями.
Акт сверки банковского баланса (CSV)
Конечный банковский остаток сводится к учётному остатку; итог корректировок постатейно сверяется с реестрами расхождений (расхождение 0.00).
